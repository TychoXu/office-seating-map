# 办公室工位图

一个交互式办公室工位分布图，用于直观展示办公区域、人员座位及公共空间布局。

## 功能介绍

- 展示办公室整体平面布局和工位分布
- 标注会议室、CEO 办公室、电话亭、茶水间、休息室及财务室
- 展示员工姓名及所在工位
- 提供总座位、已使用和空余座位的实时数字看板
- 内置完整 ORG-CHART 人员资料，支持通过英文简称、英文全名或中文名匹配人员
- 点击员工工位可查看中文名、英文名、部门、职务和工位信息
- 支持按中文名或英文名搜索员工并定位对应工位
- 支持在线编辑工位人员信息
- 支持导出工位 JSON 数据
- 支持将工位图导出为 PNG 图片或 PDF 文件
- 展示会议桌、协作桌、座椅、办公设备及绿植等设施
